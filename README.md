# Portfólio Digital — Arte, Técnica e Tecnologia

Projeto da disciplina **Tecnologia e Humanidades** (TSI) — 2ª Avaliação.
Desenvolver um site em HTML e CSS que funciona como um portfólio digital,
reunindo produções práticas e reflexões sobre a relação entre arte, técnica
e tecnologia.

## Sobre o projeto

O site reúne quatro atividades práticas, cada uma em uma página própria,
interligadas por um menu de navegação:

| Página | Atividade | Descrição |
|---|---|---|
| [index.html](index.html) | Apresentação | Alunos, curso, turma e introdução do projeto |
| [arte-ia.html](arte-ia.html) | Arte com IA | Imagem gerada por IA sobre exclusão digital, com prompts e registro das tentativas de refinamento |
| [pixel-art.html](pixel-art.html) | Pixel Art | Personagem/logo em 10x10 pixels |
| [glitch-art.html](glitch-art.html) | Glitch Art | Modificação intencional de imagem de Teresina com estética de falha digital |
| [css-art.html](css-art.html) | Pincel de Código (CSS Art) | Releitura de obra geométrica de Mondrian em HTML/CSS puro |

## Como visualizar

Basta abrir o `index.html` no navegador, ou rodar um servidor local:

```bash
python -m http.server 8000
```

Depois acesse <http://localhost:8000>.

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox, media queries)
- Nenhuma imagem pronta na composição CSS Art
